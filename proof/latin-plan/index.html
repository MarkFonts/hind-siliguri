What you'd draw: Ħ ħ ẞ

These are the glyphs already in the font that set the rules.

  • Ħ: a bar across both stems, between the crossbar and the cap height. Eth's bar sets the weight, and how far it overshoots the stem.
  • ħ: a bar across the ascender, matching dcroat's.
  • ẞ: width and weight between ß and B.
  • Both masters, compatible. Same contours, same order, and the same start node in Light and Bold. Mismatched start nodes and contour order are what broke ১, হ্র, and ল্দ্র here, so the build will scan for both.
  • Draw them in masters/HindSiliguri.glyphs as Hbar, hbar, and Germandbls. I'll wire up everything else around them.

Where: Siliguri first, then Hind

You asked whether to start in Hind. I'd start here. The two forks don't carry quite the same Latin:

  • Siliguri has the newer drawing. Its Latin is the October 2015 revision, from hindkit 0.3.0's Hind.glyphs. The Hind fork's comes from the 2014 UFOs. In 2015, ITF corrected Ţ ţ from a comma below (the Romanian form, wrong for these code points) to a real cedilla.
  • Siliguri's masters are compatible. About a dozen glyphs (e, g, n, æ, X, <, ≤, the braces) have mismatched contours between Hind's masters and match here.
  • The checks run here. This repo already builds with gftools and passes fontbakery apart from these 34.

Then a variant of toolchain/merge_latin_into_glyphs.py carries the whole Latin into Hind.glyphs: the 2015 fixes plus the new glyphs. After that, the other four families take the same Latin unchanged.

Ţ ţ, Light and Bold. The other differences are in contour order only and don't show.

What I'd do around your drawing

  1. Add the 16 composites as components, at the placements above, with your corrections. Add dotless ȷ and the combining comma as outlines.
  2. Give the base letters top and bottom anchors in both masters. The anchor positions follow from the accented letters already in the font, so ufo2ft (and hindkit) generate mark positioning for decomposed text, such as e followed by U+0301.
  3. Add the 13 combining marks as zero-width components of the spacing accents, with matching _top and _bottom anchors and the Mark category.
  4. Add a small ccmp rule: i and j become dotless before a mark above (Lithuanian, Dutch íj́).
  5. Update the GOADB, rebuild with hindkit and gftools, and rerun fontbakery. Check composed against decomposed text in a rendered proof.
  6. Port the Latin to Hind and re-verify it against the 2014 OTFs.
